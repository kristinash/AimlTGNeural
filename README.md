# AimlTGNeural

Учебный проект на C#: нейронная сеть для распознавания образов и Telegram-бот, который распознаёт рукописные цифры на фото и поддерживает диалог на AIML.

**Стек:** C# (.NET Framework), Windows Forms, Accord.Neuro, AForge, AIMLbot, Telegram.Bot

## Что умеет проект

- Распознаёт 4 фигуры: треугольник, прямоугольник, круг, синусоида (вход 20×20 пикселей = 400 нейронов, 4 выхода).
- Распознаёт рукописные цифры с камеры: кадр обрезается, переводится в оттенки серого и бинаризуется.
- Принимает фото цифры в Telegram и отвечает: «Я вижу цифру: N».
- Поддерживает текстовый диалог: бот-«исследователь нейросетей» работает на правилах AIML (русский язык).

## Структура репозитория

| Папка | Что внутри |
|---|---|
| `NeuralNetwork1` | Стенд Windows Forms для распознавания фигур; собственная нейросеть и версия на Accord.NET для сравнения |
| `NeuralNetwork2` | Распознавание цифр с веб-камеры: обработка изображения, выделение признаков, сеть |
| `NeuralNetrworkTLGBot` | Telegram-бот: фото → нейросеть → ответ; текст → AIML |
| `AIMLTGBot` | Telegram-бот только с AIML-диалогом (29 правил на русском, запоминает имя пользователя) |

## Нейронная сеть (`StudentNetwork.cs`)

Многослойный перцептрон, написанный с нуля, без готовых библиотек:

- прямой и обратный проход (backpropagation), сигмоида, кросс-энтропия;
- инициализация весов по Ксавье, нормализация входов;
- momentum и weight decay;
- обучение мини-батчами (по 16 примеров), разбиение 80/20 на обучающую и валидационную выборки;
- адаптивная скорость обучения (растёт при улучшении, падает при застое);
- ранняя остановка при отсутствии улучшения.

## Как запустить

1. Откройте решение в Visual Studio, восстановите NuGet-пакеты.
2. Создайте у бота токен в [@BotFather](https://t.me/BotFather).
3. Сохраните токен в файл `TGToken.txt` (для `AIMLTGBot`) или `botkey.txt` (для `NeuralNetrworkTLGBot`). **Эти файлы нельзя коммитить**: они указаны в `.gitignore`.
4. Запустите проект и отправьте боту фото цифры или текстовое сообщение.

## Источник и вклад

Каркас проекта (интерфейс стенда, работа с камерой, базовые классы сети и образа) взят из заданий курса. Самостоятельно выполнены: реализация нейронной сети `StudentNetwork`, подготовка данных и признаков для цифр, интеграция сети в Telegram-бота и сценарий диалога на AIML.

## Ограничения

- Датасет в репозитории небольшой и служит примером, на нём нельзя судить о реальной точности.
- Качество распознавания цифр зависит от освещения и аккуратности написания.
